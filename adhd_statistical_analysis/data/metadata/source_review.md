# Source verification notes

Accessed 2026-10-20. Original sources were inspected, not inferred from previous slides.

- Figshare API 24906924, v1: published 2024-01-04, modified 2024-01-05, CC BY 4.0, one file named `Student Mental Health Article Data.xlsx`, file ID 43834113, 255,537 bytes, MD5 `bc660db1fb08d0abf743fce735073ffa`. Local file and downloaded public bytes are identical. No codebook or repeated-wave workbook is attached.
- Mohamad et al. (2025), Methods: ASRS 18 items 0–4, inattention 1–4 and 7–11, hyperactivity/impulsivity 5–6 and 12–18; no reverse items specified. AAS higher intended better, nine 1–5 responses. Weighted GPA requires course credits; `psy1004_grade` does not match reported GPA descriptives. Missing ASRS/BAI values were imputed by the study authors, but the release has no cell-level flags. Paper reports 506/332/180 waves; source release does not supply those repeated item sets or IDs.
- Sarid & Lipka (2023), Participants: COVID sample n=330, ADHD only n=68, no LD/ADHD n=197. Table 3 A/C: academic 6.04 (1.17)/5.55 (1.04), social 6.03 (1.25)/5.41 (1.49). Procedures describe requesting recent certification and telephone diagnosis/institution confirmation, with same procedures for the COVID sample. SACQ adapted Hebrew subscales, 1–9 and higher better; academic 22 items, social 7. The table is a four-group study; our focus is a different two-group analytical contrast. Source HTML is cached.
- Original AAS author-uploaded appendix (Anderson, Guan & Koc, 2016): original-order items 2 and 3 are negative/reverse-scored. This was readable using the public web search rendering at https://www.researchgate.net/publication/305617123_The_AAS_-_appendix . Direct programmatic archival request returned 403, which is logged rather than represented as a saved document. It does not prove the released item order or recoding state. No score is recoded by guessing from correlations.
- Gormley et al.: online 2016, issue 2019. Table 1 GPA-difference sample n=278 (133 ADHD/145 comparison). Table 2 fall 2.91 (.77)/3.26 (.69), spring 2.79 (.84)/3.13 (.82). Published adjusted ANCOVA p=.002/.013. No new tests are run from those context values; Table 2 simple t entries do not map cleanly to stated analysis Ns. Fall and spring are repeated outcomes, not independent samples.
- Lipka et al. (2020) Table 3 combines ADHD/LD (n=67). Academic 5.76 (1.03) vs 6.40 (1.12); social 6.16 (1.26) vs 6.47 (1.14). Overall abstract and table counts differ. Context only; not ADHD-only data.
- Baczewski et al. (2022): three matched groups n=74 each, self-identified diagnoses, start/end first-year survey completers. Bonferroni cutoff .008. Adjusted intellectual confidence p=.32, psychological stress p=.02, belonging p=.22, campus satisfaction p=.10; balancing demands p=.10. Full text does report an academic-success omnibus p=.003 and autism-vs-ADHD p=.002, despite broad abstract language suggesting other outcomes did not differ. Social-confidence differences concern autism versus ADHD/NT, not a universal ADHD-vs-NT deficit.
- Kazakhstan screening: Yertukeshova et al. (2024), 576 students, GHQ-12 and achievement motivation, no ADHD exposure. Statement that data are in the article does not provide comparable ADHD participant-level records. No Kazakhstan data enter any hypothesis test.
